# Crow Integrated Island Feature Visual Briefs

These briefs generate feature-specific Crow Island designs using the top-edge integrated black bar style.

Shared direction:

```text
Mac top edge -> integrated black bar -> downward rectangular expansion
```

Common constraints for all images:

- The black Crow bar is fused into the top center edge.
- The left side of the bar contains a small Crow icon.
- The center contains the current state or task label.
- The right side contains activity bars, waveform, or status indicator.
- Expanded panels grow downward from the same top bar.
- Use rectangular dropdown panels with modest corner radius.
- Do not use detached floating cards.
- Do not use chat bubbles as the primary layout.
- No humanoid assistant, mascot character, copyrighted logos, or watermark.
- Keep text readable.
